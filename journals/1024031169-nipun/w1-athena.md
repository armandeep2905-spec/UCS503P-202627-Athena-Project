# Week 1 — Project Ideation, Selection and Initial Documentation

## Problem / Challenge

During the initial stage of the project, our team had to present four different project ideas. Since all four ideas had different scopes and possible implementations, I was initially confused about which project would be most suitable for the Software Engineering project.

The selected project was **Athena**, an AI-powered campus assistance platform. After selecting Athena, another challenge was defining its scope clearly and explaining what would make the project different from a generic chatbot.

## Relevant Context

The initial concept of Athena was discussed as a campus-focused AI assistant that could understand student queries and provide institution-specific information.

The major feature identified during the discussion was the combination of:

- Large Language Model (LLM)
- Retrieval-Augmented Generation (RAG)
- Natural-language interaction through a chatbot

The objective was not to create another general-purpose chatbot, but to make the system capable of answering questions using relevant institutional information.

## Key Observation

A generic LLM may provide a general answer, but a student asking a question about a particular college requires information specific to that institution.

For example:

```text
Student:
"What are the eligibility requirements for this course?"

Generic LLM:
Provides a general answer based on its existing knowledge.

Athena:
Retrieves relevant institutional information
        ↓
Provides the retrieved context to the LLM
        ↓
Generates a college-specific response
```
This led us to identify RAG as an important component of Athena.

## Solution

Athena as the project idea was finalized and defined its primary purpose as an AI-powered campus assistant.

The initial scope focused on:

Student interaction through a chatbot
Natural-language campus queries
Retrieval of relevant institutional information
Context-aware responses using an LLM
Institution-specific knowledge through RAG

After finalizing the concept, we started preparing the initial project report.
