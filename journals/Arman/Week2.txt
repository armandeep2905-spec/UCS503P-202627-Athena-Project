-> Commands i learnt and used:
* git clone <repository-url> → Clone the repository locally.
* git remote -v → Check connected remote repositories.
* git remote add upstream <repository-url> → Connect the original repository as upstream.
* git fetch upstream → Fetch the latest changes from the original repository.
* git checkout master → Switch to the master branch.
* git status → Check the current repository status.
* git add . → Stage changes.
* git commit -m "message" → Create a commit.
* git push origin master → Push changes to my fork.

-> along with some basic commands like:
* pwd → Check the current directory/location.
* ls → List files and folders.
* cd <folder> → Move into a folder.
* cd .. → Move one level back.
* mkdir <folder> → Create a new folder.
* touch <file> → Create a new file.

I overcame this by learning the commands in depth and using the CLI instead of relying on the GUI, which helped me understand each operation and maintain better control over my commits and changes.
