WEEK 4 — FRONTEND DEVELOPMENT

TASKS ACHIEVED

1. React Project Setup
   • Set up the frontend using React and Vite for a fast and modern
     development environment.
   • Organized the project structure into reusable components and
     different application modules.

2. UI Design and Theme
   • Integrated Tailwind CSS for styling.
   • Created a consistent colour theme using Deep Blue, Gold, White
     and Gray.
   • Added Light and Dark mode support using CSS variables.

3. Navigation and Layout
   • Created the main PageShell layout for the application.
   • Implemented React Router for navigation between different pages.
   • Designed a tile-based dashboard to provide easy access to the
     different modules.

4. Reusable UI Components
   • Developed reusable components such as:
     - Buttons
     - Cards
     - Modals
     - Inputs
     - Loaders
   • This helped maintain a consistent design throughout the website.

5. AI Chat Interface
   • Created a floating AI Chat Panel for interacting with the
     planned RAG-based backend.
   • Added typing indicators, chat message bubbles and citation
     components for displaying referenced documents.

6. Interactive Campus Map
   • Developed an interactive campus map using a custom campus
     illustration.
   • Used coordinate-based data to place clickable building hotspots.
   • Added popups to display building information.

7. Academic and Student Modules
   • Developed frontend views for:
     - Courses
     - Faculty Directory
     - Exam Date Sheets
     - CGPA Calculator
     - Societies
     - Events

8. State Management and Testing
   • Used React Context for managing authentication, theme and
     institution selection.
   • Created mock JSON data to test the frontend before connecting it
     to the Django backend.
   • Resolved React/Vite dependency issues and verified that the
     frontend builds successfully without errors.


PROBLEMS / DIFFICULTIES FACED

• Faced dependency and package-linking issues while setting up React
  and Vite, which were resolved by correcting the required packages.
• Managing common UI states such as authentication, themes and
  institution selection required a centralized state-management
  approach, which was handled using React Context.
• Implementing the interactive campus map required mapping coordinate
  data to the custom campus illustration so that buildings could be
  displayed and selected correctly.


FINAL OUTCOME

• Successfully developed the main React frontend with a consistent
  and responsive UI.
• Implemented navigation, reusable components, themes, AI chat,
  campus map and academic/student modules.
• Created mock data for frontend testing and prepared the application
  for integration with the Django backend.
• Verified that the frontend builds successfully without production
  errors.
